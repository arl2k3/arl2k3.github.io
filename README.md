# Harryson Montesdeoca

Personal site for [arl2k3.github.io](https://arl2k3.github.io). Static HTML, CSS, and JavaScript served from the repository root. Spanish by default, with an English toggle.

## Preview locally

From the repository root:

```bash
python3 -m http.server 4173
```

Open `http://127.0.0.1:4173`.

## GitHub Pages

This repository is a user site. Pages is configured to publish the `main` branch from `/` (root). Merging into `main` updates [https://arl2k3.github.io](https://arl2k3.github.io). No build step and no Actions workflow are required.

`.nojekyll` is present so GitHub Pages serves the files as-is.

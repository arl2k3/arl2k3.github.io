01 Sobre mí

Software con usuarios reales, de la pantalla a la base de datos.

Diseño, construyo y mantengo aplicaciones que ya están en uso.

Soy desarrollador full stack en SAGAT Systems, en Quito. En el backend trabajo con C#, ASP.NET Core (.NET 8) y Entity Framework Core. En el frontend, con Angular 14+, TypeScript, RxJS y Angular Material. En móvil, con Flutter.

También administro SQL Server: procedimientos almacenados, triggers, vistas, índices y el aprovisionamiento de bases nuevas. Despliego en IIS, uso Git a diario y trabajo en Scrum. Si algo falla en producción, lo reviso y lo dejo estable.

Estudio Ingeniería en Software en la Escuela Politécnica Nacional, noveno semestre. Español nativo e inglés C1. Además he trabajado con Java Spring Boot, Python y Node.js.

02 Servicios

Qué construyo

Cuatro frentes en los que puedo entrar a un producto y dejar la web, la API, los datos y el móvil hablando el mismo idioma.

Web y landing pages

Interfaces de producto y páginas de aterrizaje. En el trabajo diario es Angular. Cuando hace falta presentar algo con claridad y velocidad, también HTML, CSS y JavaScript.

  • Angular 14+, TypeScript y manejo de estado con RxJS.
  • Formularios reactivos, Angular Material y consumo de APIs REST.
  • Landing pages cuidadas en móvil, jerarquía visual y rendimiento.

Ejemplo ilustrativo del tipo de código que escribo.

APIs y backend

APIs REST que la web y el móvil pueden compartir. Autenticación, autorización y un acceso a datos que se puede seguir manteniendo.

  • ASP.NET Core sobre .NET 8, con contratos REST claros.
  • JWT y ASP.NET Identity para autenticación y roles.
  • Entity Framework Core como capa de acceso a datos.

Ejemplo ilustrativo del tipo de código que escribo.

Bases de datos

SQL Server entra en el diseño, no al final. Modelo, consultas, índices y la operación del día a día: respaldos, restauración y bases nuevas.

  • Procedimientos almacenados, vistas y triggers.
  • Índices y optimización de consultas.
  • Aprovisionamiento de bases, backup y restore.

Ejemplo ilustrativo del tipo de SQL que escribo.

Apps móviles

Aplicaciones multiplataforma en Flutter, apoyadas en las mismas APIs que usa la web. Una base de código para iOS y Android.

  • Interfaces en Flutter conectadas a APIs REST.
  • La misma autenticación y los mismos recursos que la web.
  • Un solo código para iOS y Android.

Ejemplo ilustrativo del tipo de código que escribo.
